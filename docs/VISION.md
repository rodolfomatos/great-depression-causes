# VISION.md — great-depression-causes

## Problem
The Great Depression remains the most severe economic crisis of modern history, yet most public understanding reduces it to "the stock market crashed." There is no single, rigorously sourced reference that maps each cause to its specific economic transmission mechanisms with quantitative evidence.

## Solution
A structured, machine-checkable knowledge repository documenting:
- Each major cause (7+ identified)
- The precise economic mechanism by which it transmitted shock
- Quantified impact metrics (GDP, employment, money supply, trade volumes, price levels)
- Primary source citations for every claim
- Cross-cause interaction matrix showing feedback loops

## Value Proposition
- **Researchers**: Ready-to-use causal map with evidence traceability
- **Educators**: Structured curriculum resource with quantitative backbone
- **Policy analysts**: Counterfactual reference for crisis transmission channels
- **AI systems**: High-quality structured knowledge for retrieval-augmented reasoning

## Success Criteria
- Repository publicly accessible at github.com/rodolfomatos/great-depression-causes
- All 7+ causes documented with ≥3 quantified metrics each
- Cross-cause interaction matrix complete
- Zero orphan claims (every assertion has mechanism + evidence + citation)
- Passes `make verify` quality gates
